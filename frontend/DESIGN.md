# digem 디자인 방향

홈과 앨범 목록은 레코드숍의 간판과 진열대처럼 연결한다. 조용하고, 수집가답고, 손때 묻은 느낌을 목표로 한다.

앰버색 CRT, digem 로고, 모노 서체를 유지한다. 화면에서 가장 큰 색의 변화는 앨범 커버 원본에서 온다. CRT 잔광과 스캔라인은 홈에 두고, 앨범 목록에서는 커버와 글자가 효과에 가려지지 않게 한다.

홈의 로고, 태그라인, 탐색 링크는 같은 왼쪽 기준선에 놓는다. 앨범 목록은 커버, 제목, 아티스트, 발매 정보 순으로 읽힌다. 추천 표시는 발매 정보 줄에 두고, 필터에는 선택 상태만 강조한다. 색과 간격은 기존 CSS 토큰을 쓴다.
